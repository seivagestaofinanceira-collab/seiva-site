# Site institucional — Seiva Gestão Financeira

Site institucional estático, responsivo e em português brasileiro.

## Arquivos
- `index.html`: conteúdo e estrutura.
- `styles.css`: identidade visual e responsividade.
- `script.js`: menu móvel e ano automático.

## Antes de publicar
1. Revise textos, serviços e contatos.
2. Confirme que o telefone `+55 54 99636-2049` e o e-mail `contato@seivafinancas.com.br` estão corretos.
3. As imagens de fundo são carregadas do Unsplash e exigem conexão com a internet.
4. Este primeiro pacote ainda não inclui o editor visual; a área de edição será configurada depois da publicação inicial.

## Publicação
Este projeto pode ser conectado a Cloudflare Pages usando o repositório GitHub. Framework preset: `None`; build command: deixar em branco; build output directory: `/` ou diretório raiz do projeto, conforme a interface atual.
